# Kampüs Etkinlikleri

Web Teknolojileri ve Programlama dersi Sprint 1 ödevi. Kampüs içindeki 
seminer, atölye ve etkinlikleri tek bir yerden takip etmeyi sağlayan, 
sadece HTML ile hazırlanmış statik prototip.

## Canlı Adres

https://kampus-etkinlik-green.vercel.app/

## Sayfalar

- `index.html` — Ana sayfa, uygulama tanıtımı ve öne çıkan etkinlikler
- `etkinlikler.html` — Tüm etkinliklerin listesi ve aylık program özeti
- `etkinlik-detay.html` — Bir etkinliğin ayrıntılı bilgisi
- `etkinlik-ekle.html` — Yeni etkinlik ekleme formu
- `etkinlik-guncelle.html` — Var olan etkinliği güncelleme formu

## Kapsam

Bu sprintte sadece HTML kullanıldı; CSS ve JavaScript yok. Veri kaydı 
yapılmıyor, formlar statik.
